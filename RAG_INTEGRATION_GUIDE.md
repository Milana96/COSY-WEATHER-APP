# RAG Integration Guide for the Weather App

## 1. A good RAG idea for this app

Turn the weather dashboard into a “Weather Coach” experience.

Instead of only showing live weather and forecasts, the app can answer questions like:

- “What should I wear in Tokyo tomorrow?”
- “Will this rain affect my outdoor run?”
- “How should I prepare for a windy day in Reykjavik?”
- “What are the best clothes for high humidity?”

This fits your current app very well because the weather screen already has:

- live weather data
- city-based context
- forecast information
- a UI that can easily host a chat panel

The RAG flow should combine:

- the user’s question
- the current weather context from your app
- retrieved knowledge from a document store
- a response generated by Ollama

---

## 2. Recommended architecture

The cleanest setup is:

- React frontend: keep the current UI and add a chat box
- Express backend: expose a new endpoint for the RAG query
- Python RAG service: handle chunking, embeddings, Chroma storage, and retrieval
- Ollama: generate the final answer

Why Python here?

- Chroma + embedding workflows are very smooth in Python
- Nomic embeddings are easiest to use in a Python environment
- Ollama is simple to call from Python

A practical folder structure:

```text
rag/
  data/
    weather_knowledge.md
  ingest.py
  query.py
  requirements.txt
```

Your frontend can continue to live in the existing React app, while the backend uses the Python service through HTTP.

---

## 3. What to put into the knowledge base

Create a document file such as:

```text
rag/data/weather_knowledge.md
```

Put useful content in it, for example:

- clothing advice for different temperatures
- rain and wind safety tips
- what to carry in hot, cold, or humid weather
- general travel and outdoor planning advice
- app-specific rules such as “When the forecast shows heavy wind, recommend layers”

Example content:

```md
# Weather Guidance

## Cold weather
If the temperature is below 10°C, recommend a warm jacket, layers, and gloves.

## Rainy weather
If rain is likely, suggest a waterproof jacket and shoes with grip.

## High humidity
In high humidity, recommend light breathable clothing and extra water.

## Windy weather
For strong wind, recommend windproof outerwear and secure accessories.
```

## 4. Step-by-step implementation

### Step 1: Install the needed tools

Install Ollama locally and pull a model.

```bash
ollama serve
ollama pull llama3.2:3b
```

Install Python dependencies:

```bash
pip install chromadb sentence-transformers transformers torch requests
```

---

### Step 2: Split text into chunks

Before storing anything, split the knowledge base into smaller pieces.

Good defaults:

- chunk size: 500–800 characters
- overlap: 100–150 characters

This helps retrieval stay focused and accurate.

Example logic:

```python
def chunk_text(text, chunk_size=700, overlap=120):
    chunks = []
    start = 0
    while start < len(text):
        end = start + chunk_size
        chunk = text[start:end]
        chunks.append(chunk.strip())
        if end >= len(text):
            break
        start = max(0, end - overlap)
    return chunks
```

---

### Step 3: Convert chunks into embeddings with Nomic

Use a Nomic embedding model such as:

```text
nomic-ai/nomic-embed-text-v1.5
```

Example code:

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5")

embeddings = model.encode(chunks)
```

This step turns each text chunk into a vector.

---

### Step 4: Save the embeddings into Chroma

Create a persistent Chroma database.

Example code:

```python
import chromadb

client = chromadb.PersistentClient(path="./chroma_db")
collection = client.get_or_create_collection(name="weather_knowledge")

collection.add(
    documents=chunks,
    embeddings=embeddings.tolist(),
    ids=[f"chunk-{i}" for i in range(len(chunks))],
)
```

This stores the text chunks and their embeddings so you can search them later.

---

### Step 5: Build the retrieval query flow

When the user asks a question, your app should:

1. take the user query
2. add current weather context from the app
3. embed the combined query
4. search Chroma for the most similar chunks
5. pass those chunks to Ollama for answer generation

Example query logic:

```python
query = f"{user_question}\nCurrent weather: {weather_context}"
query_embedding = model.encode([query])[0]

results = collection.query(
    query_embeddings=[query_embedding.tolist()],
    n_results=4,
)
```

You should retrieve the top 3–5 chunks.

---

### Step 6: Generate the final answer with Ollama

Use the retrieved chunks as grounding context.

Example prompt:

```text
You are a weather assistant.
Use only the context below to answer the user question.
If the answer is not in the context, say that you do not know.

Context:
{retrieved_text}

User question:
{user_question}
```

Python example:

```python
import requests

payload = {
    "model": "llama3.2:3b",
    "prompt": prompt,
    "stream": False,
}

response = requests.post("http://localhost:11434/api/generate", json=payload)
answer = response.json()["response"]
```

## 5. Suggested implementation order

If you are learning, follow this order:

1. Create the knowledge file
2. Build the chunking logic
3. Run embedding generation
4. Store vectors in Chroma
5. Test retrieval manually
6. Connect Ollama for final generation
7. Add the Express API endpoint
8. Add the frontend chat panel

This order keeps the project manageable.

## 6. Minimal starter example

### Ingestion script

```python
# rag/ingest.py
from pathlib import Path
from sentence_transformers import SentenceTransformer
import chromadb

text = Path("rag/data/weather_knowledge.md").read_text(encoding="utf-8")

# simple splitting
chunks = [chunk.strip() for chunk in text.split("\n\n") if chunk.strip()]

model = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5")
embeddings = model.encode(chunks)

client = chromadb.PersistentClient(path="./chroma_db")
collection = client.get_or_create_collection("weather_knowledge")

collection.add(
    documents=chunks,
    embeddings=embeddings.tolist(),
    ids=[f"chunk-{i}" for i in range(len(chunks))],
)
```

### Query script

```python
# rag/query.py
import sys
from sentence_transformers import SentenceTransformer
import chromadb
import requests

question = sys.argv[1]
model = SentenceTransformer("nomic-ai/nomic-embed-text-v1.5")
client = chromadb.PersistentClient(path="./chroma_db")
collection = client.get_collection("weather_knowledge")

query_embedding = model.encode([question])[0]
results = collection.query(query_embeddings=[query_embedding.tolist()], n_results=3)
context = "\n\n".join(results["documents"][0])

prompt = f"""
You are a weather assistant.
Use only the context below.

Context:
{context}

Question:
{question}
"""

response = requests.post(
    "http://localhost:11434/api/generate",
    json={"model": "llama3.2:3b", "prompt": prompt, "stream": False},
)
print(response.json()["response"])
```
